## Capstone Repository

I am uploading the simulation scripts here in order to track changes and be able to reproduce these results later on.

So far, I have kept the output files locally to prevent cluttering this repo here.


#### MD
This contains copies of the simulation files made available to me through the Math Reading Notion page.

#### NMP-kit
This contains subfolders for each part of the NMP simulation. The files shared by Andrea are in the ``\input`` folder, and the new ``.conf`` simulation scripts are in the corresponding folder (``\Minimization``,``\NVT1``, ``\NPT``, ``\NVT2``).
